How it works

  1. Create a session. Tap "Create session" on your laptop. You get a 6-character code and a QR code.
  2. Connect your other device. Scan the QR with your phone camera, or type the code under "Join with a code".
  3. Share. Paste text or upload files on one device. They appear on the other instantly, ready to copy or download.
  4. Delete when done. Press "Delete session for everyone" and all text and files are wiped from the server.

FAQ

Do I need to create an account or log in?

No. There is no sign-up and no login. Anyone with the session code can join, so keep the code to yourself.

Is Sharelah free?

Yes, it is free to use.

How big can a file be?

Up to 50 MB per file. You can upload several files at once.

How long do my files stay?

Until you delete the session, or after 2 hours with no activity, whichever comes first. A server restart also clears everything.

Can I use it between a phone and a laptop on different networks?

Yes. Devices connect through the Sharelah server, so they do not need to be on the same Wi-Fi.

Is it private?

Files are stored temporarily on the server and only people who have your code can reach them. Do not upload highly sensitive documents. Always delete the session when you finish.

Which devices and browsers work?

Any device with a modern browser: Chrome, Safari, Edge or Firefox, on phone, tablet or computer.

What can I share?

Plain text, links, code snippets, and files such as documents, images and PDFs. Handy for moving assignment work between devices.
